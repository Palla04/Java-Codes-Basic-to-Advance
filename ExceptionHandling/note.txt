Handling
  
  An exception (or exceptional event) is a problem that aries during the execution of a program.
    
    
    1. A user has entered an invalid data.
    2. A file that needs to be opened cannot be found.
    3. A network connection has been lost in the middle of communications or the JVM has run out of memory.
    
    
    
    Syntactical Error:
        
                    a=10+2
        
    Semmantic Error:
                   
                    10 = a;
                    

     ***Throwable is a class that is inherited by 
               1. Exception
               2. Error
               
            now, Exception class is again inherited by the following classes
		                  1.IOException
		                  2.SQLException
		                  3.ClassNot FoundException
		                  4.RuntimeException
                  
                      RunTimeException class is again inherited by
                         1.ArithmeticException
                         2.NullPointerException
                         3.NumberFormatException
                         4.IndexOutOfBoundsException
                        
                          IndexOutOfBoundsException class is again inherited by
                              1.ArrayIndexOutOfBoundsException
                              2.StringIndexOutOfBoundsException
             
             
             and, Error class is again inherited by the following classes
                       
                       1.StackOverFlowError
                       2.VirtualMachineError
                       3.OutOfMemoryError
                       
                       
                       
  Types of Java Exceptions:
        
        1.Checked Exception: The classes which directly inherit Throwable class except RuntimeException and Error
                             are known as checked exceptions
                             
                             e.g. IOException, SQLException etc.
                             Checked Exception are checked at compile time.
                             
        2.Unchecked Exception: The classes which inherit Runtime Exception are known as unchecked exception.
                              
                             e.g. ArithmeticException,
                             NullPointerException,
                             ArrayIndexOutOfBoundsExcention etc.
        3.Error:  Error is irrecoverable
                  e.g. OutOfMemoryError
